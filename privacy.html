운명코드 0.99.9

개인정보처리방침

최종 수정일: 2026년 10월 23일 · 운명코드 0.99.9 기준

1. 루미·노바·정연 사주에서 사용하는 정보

운명코드의 루미·노바·정연 기능은 사용자가 직접 입력한 생년월일, 출생시간, 성별, 선택적 닉네임, 선택적 한글/한자 이름을 사주 및 선택적 이름 풀이 계산에 사용합니다.

사용자가 “입력내용 저장하기”을 선택한 경우 해당 정보는 앱의 기기 로컬 저장소에 저장됩니다. 운명코드 0.99.9에는 이 정보를 운명코드 자체 서버로 업로드하는 기능이 없습니다.

2. 보관과 삭제

저장된 공통 사주 프로필은 사용자가 삭제할 때까지 기기 내부에 남을 수 있습니다. 정연 화면의 “저장한 출생정보 삭제” 기능으로 삭제할 수 있으며, Android 앱 백업은 비활성화되어 있습니다.

앱 제거 또는 앱 데이터 삭제 시 운영체제 동작에 따라 로컬 데이터가 삭제될 수 있습니다.

3. 네트워크 사용

사주 계산과 일부 콘텐츠는 앱에 포함된 자료로 작동합니다. 타로·나BTI 등 일부 콘텐츠 및 공유 결과의 웹페이지는 개발자가 운영하는 GitHub Pages에서 불러올 수 있으므로 인터넷 연결이 필요할 수 있습니다. 사용자가 기기에 저장하는 프로필과 최근 결과는 로컬 저장소에서 관리됩니다.

웹 호스팅 또는 네트워크 제공자가 IP 주소, 요청 시각, User-Agent 등 일반적인 웹 요청 정보를 처리할 수 있습니다.

4. 카카오톡 공유

사용자가 카카오톡 공유 기능을 직접 실행한 경우에만 결과 제목, 설명, 연결 링크가 Kakao SDK를 통한 공유 절차에 사용됩니다. 전체 출생정보를 자동 전송하지 않습니다. 타로·나BTI 공유 링크에는 별명, 선택 카드 또는 테스트 점수가 포함될 수 있으므로 공유 전 내용을 확인할 수 있습니다.

5. 광고·분석·결제

운명코드 0.99.9에는 광고 SDK, 분석 SDK, 인앱결제 또는 구독 SDK를 포함하지 않습니다. 1.0 이후 광고 또는 유료 기능을 추가하면 실제 데이터 처리에 맞게 본 방침과 Google Play Data safety 정보를 갱신합니다.

6. 이용 목적

사주, 운세, 성명 풀이는 오락 및 자기성찰을 위한 참고 콘텐츠입니다. 의료, 법률, 재무, 채용, 보험 등 중요한 의사결정을 대신하지 않습니다.

7. 제3자 서비스

  • Kakao SDK — 사용자가 공유 기능을 실행할 때 사용
  • GitHub Pages — 개인정보처리방침 및 사용자가 공유한 결과의 웹페이지 제공
  • Google Play — 앱 배포 및 스토어 기능

각 제3자 서비스가 독립적으로 처리하는 정보에는 해당 서비스의 개인정보처리방침이 적용될 수 있습니다.

9. 변경

광고, 분석, 계정, 클라우드 동기화, 결제 또는 새로운 외부 SDK가 추가되면 변경 내용을 반영하고 시행일을 표시합니다.

사주 공유 링크에는 사용자가 공유한 별명·핵심 해석·오늘의 행동·짧은 설명이 포함됩니다. 생년월일과 출생시간은 포함하지 않으며 링크를 받은 사람은 해당 내용을 볼 수 있습니다.
